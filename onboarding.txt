## 4. Development Setup
### Installation and Environment Setup


```bash
# Install Node.js (using nvm recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18.16.0
nvm use 18.16.0
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Frontend .env example:
```env
PORT=3001
```

Backend:
```bash
cd backend
npm install
nodemon table
nodemon sort
```

Backend .env example:
```env
PORT=3001
```

## 5. Installation and Run
- Frontend: from `frontend/` run `npm run dev` (defaults to http://localhost:3000)
- Backend: from `backend/` run `nodemon table` and `nodemon sort` in separate terminals (listens on PORT from `.env`, e.g., 3001)
